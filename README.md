## About

I'm a developer from **India 🇮🇳** focused on backend and full-stack development.

Most of my current work revolves around **Go, PostgreSQL, APIs, Linux, and systems programming**. I also build with React and TypeScript when a project needs a frontend.

I'm particularly interested in:

* Backend engineering & API design
* PostgreSQL & database design
* Networking & HTTP
* Linux & systems programming
* Distributed systems
* Rust
* AI / LLM applications

I learn mostly by **building things from scratch, breaking them, and figuring out why they broke.**
